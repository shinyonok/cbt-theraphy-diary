# CBT Therapy Diary

Фронтенд-проект, реализующий дневник когнитивно-поведенческой терапии (CBT) с модулями поведенческой активации (BA) и терапией принятия и ответственности (ACT).

## Структура

- `index.html` — точка входа для Vite и GitHub Pages.
- `src/` — исходники адаптивного веб-приложения под iPhone 13 Pro.
  - `main.ts` — инициализация UI.
  - `app/` — модульный код TypeScript для CBT/BA/ACT.
  - `tests/` — модульные тесты на Vitest.

## Основные модули

- Дневник мыслей с автоматической идентификацией когнитивных искажений и подсказками для переоценки.
- Трекер настроения и энергии.
- Планировщик активирующих действий.
- Дыхательные и релаксационные упражнения.
- Менеджер напоминаний и микро-ритуалов.

### Устранение неполадок

- Ошибка вида `vite binary unavailable` или `vitest binary unavailable` означает, что не были
  установлены npm-зависимости. Выполните `npm install`, чтобы загрузить и подготовить Vite/Vitest.
- Если установка завершается ошибкой `403 Forbidden`, это сигнализирует об отсутствии доступа к
  реестру npm (например, в изолированной среде без интернета). В таком случае загрузите пакеты в
  среде с доступом в сеть либо настройте внутренний зеркальный реестр и повторите `npm install`.

## Деплой на GitHub Pages

1. Включите GitHub Pages для репозитория (Settings → Pages → Build and deployment → GitHub Actions).
2. Основной workflow `.github/workflows/deploy.yml` собирает проект через Vite и публикует артефакт в Pages.
3. Любой пуш в ветку `main` автоматически перезапускает деплой. Результат будет доступен по адресу
   `https://<ваш-логин>.github.io/cbt-theraphy-diary/`.

Данные сохраняются через IndexedDB (с памятью в качестве запасного варианта) и готовы к работе в браузере.
